# Homowork 1. Анализ продаж

В работе исследуются продажи товара PARTY BUNTING (47566). Для анализа использован датасет Online Retail из UCI Machine Learning Repository. Анализируется количество проданных штук по всем странам за период с 01.12.2010 по 09.12.2011.

## Что сделано

1) Построены дневной, недельный и месячный ряды продаж.
2) Проверены пропуски и дни без зарегистрированных продаж.
3) Выявлены потенциальные выбросы методом IQR.
4) Рассчитаны описательные статистики, скользящие среднее и стандартное отклонение.
5) Выполнена STL-декомпозиция с недельным периодом.
6) Сезонность исследована по дням недели, ACF и спектральной плотности мощности, оцененной методом Уэлча.
7) Стационарность проверена тестами ADF и KPSS до и после ряда преобразований.


## Основные результаты

1) После проведения отбора осталось 1706 записей и 18295 проданных гирлянд, для агрегаций по дню, недели и месяцу получено соответственн 374 дневных, 54 недельных и 13 месячных наблюдений.

2) Пропусков в необходимых для расчета продаж полях нет. Обнаружено 80 дней без продаж гирлянды: в 11 были другие транзакции магазина, в 69 транзакций вообще нет.

3) Для поиска выбросов воспользовался методом IQR, который отметил 26 потенциальных выбросов. По итогу анализа крупные объемы сохранены, так как они могут соответствовать оптовым заказам, а явных оснований считать их ошибками не найдено.

4) Рассчитаны описательные статистики ряда, выявлен недельный тренд, проведена аналитика стационарности ряда.
